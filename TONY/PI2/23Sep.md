## ANÁLISIS TÉCNICO-OPERATIVO

Que un proyecto sea **operativamente viable** significa que **se cuenta con la infraestructura necesaria** para desarrollarlo.  
Que sea **técnicamente viable** significa que **se cuenta con el conocimiento y la tecnología necesaria** para llevarlo a cabo.

Conceptualmente, estos dos aspectos funcionan como **filtros** para evaluar un proyecto.

El **punto de partida del Análisis Técnico-Operativo** son las **soluciones para el cliente**.

### **Definición del sistema óptimo / ideal**

Es importante poder definir un sistema **por lo que es, conceptualmente**, ya que esto permite tener una **visión global y sistémica** del mismo.  
Para esto se deben especificar sus **características y requisitos funcionales**.

- **Requisitos funcionales**: funciones necesarias que debe cumplir el sistema.    
- **Requisitos no funcionales**: describen **cómo** se deben cumplir los requisitos funcionales, apoyando su desarrollo y eficiencia.

*Para el proyecto*: Describir el soft y hard necesario y la infraestructura para ello.
