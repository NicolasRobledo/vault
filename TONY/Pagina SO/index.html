Descripción:

Este TP consiste en implementar un servidor web LAMP en Debian 13, publicando un sitio propio accesible en red local e Internet. Se realizan pruebas de acceso concurrente y descarga de archivos grandes, documentando el proceso completo.

Documentación del proceso

  • Actualización de sistema: sudo apt update && sudo apt upgrade -y
  • Instalación de Apache: sudo apt install apache2 -y
  • Archivos servidos desde: /var/www/html/
  • Archivo ISO descargado con: wget -c <URL_ISO>
  • Permisos del ISO: sudo chown www-data:www-data <ISO> y sudo chmod 0644 <ISO>
  • Acceso al sitio local: http://localhost
  • Acceso desde red local: http://192.168.1.7
